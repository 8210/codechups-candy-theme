# CodeChups Candy Theme 🍬

**CodeChups Candy Theme** is a cheerful and colorful Visual Studio Code theme inspired by the nostalgic charm of retro candy aesthetics.

This theme includes two deliciously crafted variants:
- 🍭 **CodeChups Candy Light** – Light and joyful, like a sunny day with a lemon lollipop.
- 🌙 **CodeChups Candy Dark** – A nighttime treat, soft on the eyes and full of flavor.

## ✨ Features

- Playful yet readable color palette
- Carefully balanced syntax highlighting
- Friendly UI accents inspired by candy wrappers
- Ideal for those who love a bit of sweetness in their workspace

## 🎨 Recommended Fonts

We suggest using:
- [Fira Code](https://github.com/tonsky/FiraCode)
- [JetBrains Mono](https://www.jetbrains.com/lp/mono/)
- [Cascadia Code](https://github.com/microsoft/cascadia-code)

## 📦 Installation

1. Open **Extensions** in VS Code
2. Search for `CodeChups Candy Theme`
3. Click **Install**
4. Press `Ctrl+K Ctrl+T` and select **CodeChups Candy Light** or **CodeChups Candy Dark**
